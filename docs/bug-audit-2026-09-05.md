# Bug 审计报告 — 2026-09-05

> **修复状态（2026-09-05）**：#2–#50 共 49 个已全部修复（含附带收益：ComfyUI 便携包解压由 spawnSync 改异步，主进程不再冻结数分钟）。
> 仅 #1（updater.cs 回滚守卫）因安全钩子对该文件一刀切拦截未能自动写入，补丁如下，需手动应用——`updater.cs` catch 块改为：
> ```csharp
> if (Directory.Exists(backup))
> {
>     if (Directory.Exists(appDir)) Directory.Delete(appDir, true);
>     Directory.Move(backup, appDir);
> }
> ```
> 回归：node tests 997/997、UI tests 20/20、lint 通过（context-quality 测试已按新契约更新：重复 tool 输出改保留占位符）。

> 9 个区域全量扫查（electron 主进程 / IPC 与打包 / agent 运行时 / chat 执行流 / LLM 层 / 工具层 / 记忆与批处理 / React UI / CLI 与 MCP），共 ~135 条原始发现，去重后筛选出以下 50 个最值得修的 bug。
> 标 ✅ 的为人工核实过代码现场；标 ⚡ 的为审查时实际运行复现过的。

## P0 — 破坏性

1. ✅ **P0** `updater.cs:55` — 升级器 catch 块无条件 `Directory.Delete(appDir, true)` 后才尝试从 backup 恢复。若失败发生在 backup 创建（L37）之前（zip 损坏、包校验失败），完好的 app 目录被删且无备份 → 应用直接报废，用户必须重装整个便携包。

2. ✅ `electron/ipc/presets.mjs:64` — `showSaveDialog` 的结果读的是 `result.filePaths[0]`（该属性只有打开对话框才有），保存对话框返回 `{filePath}` → 全局预设**导出功能必然报错**。

6. `src/agent/llm/openai-compatible.mjs:103-113` — 对自家默认 baseUrl `api.openai.com`：普通模型必收到不支持的 `reasoning_effort`（默认就发）、推理模型 `max_tokens`/`temperature≠1` 被 400 → **对 OpenAI 官方 API 100% 请求失败**。

8. ✅ `src/components/WorkflowSection.jsx:74` — `Number(event.key)-1` 对任意非数字键得 `NaN`，两个边界比较对 NaN 都为 false → **Alt+任意字母键清空当前工作流选择**，下次生成报"请先选择工作流"。
